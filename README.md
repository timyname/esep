# Esep

Esep is a personal AI assistant for everyday finance tracking for young people in Kazakhstan. The project is designed to lower the barrier to recording expenses without complex spreadsheets or long manual entry.

## Product flow

The service is described as a Web and Telegram product. A user can send plain text, a voice message, or a photo of a receipt. The system identifies the expense, assigns a category, stores the history, and provides personal budget guidance.

## Confirmed technology direction

- Web application and Telegram interface;
- AI-based expense classification;
- extraction from messages and receipt photos;
- local open-source LLM models;
- GPU servers for model deployment;
- SSL protection;
- infrastructure monitoring and staged scaling.

## Audience and rollout

The target audience is people aged 14–34 in Kazakhstan, especially students, young specialists, and early-stage micro-entrepreneurs. The pilot is focused on the Karaganda region, with a plan to scale across Kazakhstan.
